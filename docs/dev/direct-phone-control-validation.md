## 专用 Android 15 模拟器

同日新建独立的 Pixel 7 模拟器 Mika_Direct_API35，Android 15 / SDK 35、arm64-v8a、1080×2400，使用 SwiftShader。安装的 APK 与运行时代码提交 e321d47 的构建产物 SHA-256 一致；手机模型配置文件不存在。没有复用其他项目的模拟器数据。

运行可复现脚本：

```sh
python3 tools/mika/tests/emulator_direct_smoke.py --device emulator-5596 --output /tmp/mika-emulator-run-1 --check-idle
```

15 项设备检查全部通过，脚本总用时约 325 秒：

- MCP 握手和工具发现、无令牌 HTTP 401、CLI 开会话及会话互斥、后台启动设置与读屏。
- 在 Mika 自带测试页交替使用 MCP 和 CLI：引用点击与坐标点击使计数依次到 1、2；中文和英文输入均回读匹配；向下/向上滚动通过可见行内容核对。
- MCP 原生 PNG 和 CLI PNG 均为 1080×2400；间隔截图的像素数据不同，确认后台画面持续更新。旧快照输入被拒绝，主屏任务未变化，后台返回正常。
- 显式关闭会话、停止电脑连接后，虚拟屏和活动唤醒锁均释放；旧会话失效。
- 真实空闲期限为 300 秒，期间没有轮询手机工具续租。每 5 秒仅经 ADB 观察显示屏；约 303 秒时确认后台清理器已主动释放虚拟屏和唤醒锁，之后旧会话返回 session_not_found。

测试页的准备通过 ADB 启动，其后的读屏、截图和输入动作走实际 MCP/CLI。设备检查结果与测试页 PNG 保存到执行时指定的本机目录，未将访问令牌或连接凭据写入报告。

## 范围

三星部分验证限于该真机、已授权的 ADB 连接、系统设置 App 及本机截图；模拟器部分限于上述独立实例、系统设置及 Mika 自带测试页。没有发送消息、下单或删除用户数据；除安装与必要授权外，没有改其他系统设置。没有把原始读屏、图片、访问令牌、设备连接地址或个人标识提交仓库。

竞争调用、保护页和应用禁用等其他错误路径以单元测试为依据；空闲过期另外完成了上述模拟器实测。未将模拟器结果泛化为所有厂商真机均已通过。公网网关的直接控制入口保持不可用。使用方式见[直接控制指南](../direct-phone-control.md)。
